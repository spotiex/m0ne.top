### 1. Cloudflare 的业务
与传统互联网科技企业不同，Cloudflare 的盈利并非基于大众普通消费者市场，作为基础设施，像是互联网的"水电煤"。用非技术的例子来打个比方，全世界日常使用的各种网页服务，是你我每天出门坐上的公交车、地铁，那么 Cloudflare 就是把脚下的土地建成四通八达路网的那个角色。公交车可以换车型、地铁可以翻新车厢，但如果没有平整的路面和地下通道，再好的车辆也寸步难行。

Cloudflare 作为基础设施，承载了全球约20%网站的流量，它的商业逻辑在直觉上是反盈利的：为个人、小型团队等普通用户提供全面且**免费**的套餐。从我的了解来看，公司为个人开发者提供了几乎全部需要的网络服务，从域名解析、CDN加速、DDoS防护，到对象存储、边缘计算、无服务容器部署，低成本入手大厂小demo，无脑选它就对啦！

Cloudflare 的个人产品业务（可白嫖喵）大致描述如下，文字内容借助了 AI 生成：
```markdown
- CDN（内容分发网络）：将网站静态资源缓存到全球数据中心节点，加速访问速度，免费版无流量上限
- DNS 解析：提供快速、稳定的 DNS 解析服务，支持 DNSSEC，免费使用且不限查询次数
- DDoS 防护：免费提供无上限的 DDoS 攻击防护，覆盖 L3/L4/L7 层攻击
- SSL/TLS 证书：自动签发和续期 HTTPS 证书，免费且无需手动管理
- WAF（Web 应用防火墙）：免费版提供基础规则防护，拦截常见 Web 攻击（SQL 注入、XSS 等）
- Workers：Serverless 边缘计算平台，免费版每天 10 万次请求，支持部署 JS/WASM 代码
- Pages：静态网站托管平台，免费版无限站点、无限带宽，支持 Git 自动部署
- R2 对象存储：兼容 S3 协议的云存储，免费版每月 10 GB 存储 + 100 万次 A 类操作，且出口流量完全免费
- Images：图片存储与转换服务，免费版每月可处理 5000 张图片
- Tunnel：无需公网 IP，将本地服务安全暴露到公网，免费使用
- Zero Trust / Access：零信任访问控制，免费版支持最多 50 个用户
- Email Routing：域名邮箱转发服务，免费且不限转发规则数量
- Zaraz：第三方脚本加载管理工具，免费使用
- Speedtest（speed.cloudflare.com）：面向终端用户的网络测速工具，免费 
```
### 2. 令人琢磨的动机
从长远来看，这公司的投资真是超值，如今我大概只能想到字节在商业上的布局，有类似之处：在前期投资大众市场，砸钱提供免费服务；随着市场发展，用户养成使用习惯，无意识为产品分析迭代，贡献提供最宝贵的数据流；规模足够大之后，拥有能反向影响市场的能力，凭借其独家的流量数据，推出更具真实世界影响力的产品。

一个实际的例子是，当AI公司在互联网通过爬虫获取的训练数据时，经由Cloudflare 托管的各种网页服务，会首先捕获大量的网络流量，这意味着如果出现了某种新型的攻击行为，Cloudflare 会是首先能从数据层面进行建模分析的那一个，从而创作出最前沿的分析运维产品。这其实是一个双赢的局面，Cloudflare 为个人数字世界的所有权，提供了一道守护的防线，公司自身获得了大量真实世界数据，反过来提供更好的产品和服务。


## 二、我在使用 Cloudflare
### 1. Startup
Cloudflare 的开启十分简单，首先注册账户，其次有一个域名，通过 DNS 托管，衍生出后续一切。值得注意的是，有些个人免费服务需要绑定支付方式（对，说的就是SaaS），并不会真正地扣费，算是某种付费能力的凭证，只需验证卡片信息即可，在不超过额度的情况下，其实是永久免费的。
<img class="img-center" src="https://img.m0ne.de5.net/i/2026/05/11/b77wrs-1c49.png" alt="startup!" />
域名托管的操作简单，在域名购买商填写两个 NS(Name Server) 服务器，这两个服务器在域名托管的过程中由Cloudflare给出。这步操作的意思是，今后这个域名由我Cloudflare来管理了，有啥事来找这俩。至此，用户已经有了一个全栈的云端机房。
